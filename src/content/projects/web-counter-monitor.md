A Manifest V3 extension that watches a counter on a page and fires a desktop notification
the moment the value changes. Built to cut response time when a recovered stolen phone's
IMEI appears in a stolen-device registry — no more leaving the tab open to refresh.

Stack: JavaScript, Chrome Extension Manifest V3.
